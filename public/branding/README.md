# VentusGPT Brand Assets

Replace the legacy product identity with the supplied VentusGPT logo family.

Recommended usage:
- `logo-primary.png`: full wordmark on light surfaces
- `logo-white.png`: full wordmark on dark/colored surfaces
- `mark-primary.png`: compact app/favicon mark
- `mark-white.png`: compact mark for dark surfaces
- `favicon.svg`: browser/app icon

The source artwork supplied by the team is stored outside this text manifest. Binary assets should be added to these paths when repository binary upload is available.

Brand direction:
- Product name: VentusGPT
- Voice: scientific, calm, intelligent, modern
- Primary mark: circular dot + diagonal rounded stroke
- Avoid generic weather-cloud iconography
- Use the mark consistently in navigation, auth/loading states, metadata, favicon and social preview
